# Bright-Coffee-Shop
Data Analysis for Bright Coffee Shop
 
# Overview

This repository contains a data analysis project conducted for Bright Coffee Shop. The primary goal of this analysis is twofold:

Insights: To uncover key patterns and trends from the dataset that reflect customer behavior, sales performance, and product demand.

Recommendations: To provide actionable suggestions and strategic initiatives that can help Bright Coffee Shop improve revenue growth and overall product performance.

# Project Objectives

Transform raw data into meaningful insights.

Present clear, data-driven recommendations.

Use visualizations to make findings simple, engaging, and easy to interpret.

Develop a roadmap of the analysis process for transparency and structure.

# Tools & Technologies

The following tools were used in this project:

Excel – Data cleaning, preparation, and initial analysis.

Snowflake – Cloud-based data management and querying.

PowerPoint – Visual presentation of analysis findings.

Canva – Design enhancements for presentation materials.

Miro – Used as a visual roadmap to guide and document the analytical process.

# Data Visualization

To communicate insights effectively, simple yet impactful visualizations were used:

Bar Graphs: To compare product sales, revenue categories, and time-based performance.

Line Graphs: To track sales trends and growth patterns over time.

Pie Charts: To display proportional data such as product category shares or customer segments.

Each graph is accompanied by a short description to provide context and highlight the key takeaway.

# Key Deliverables

Data Insights Presentation: Visual summary of findings.

Recommendation Report: Strategic actions for improving performance.

Miro Roadmap: Overview of how the analysis was structured and executed.
